# Local category artwork

The eight `field-*.svg` files are original, locally bundled vector illustrations created for Fieldnotes. Each category has a different visual metaphor and an embedded, lightweight SVG animation:

- Reconnaissance: camera lens scan / focus
- Scanning: rotating radar sweep
- Web testing: browser and moving code scan line
- Cryptography: lock shackle animation and cipher marks
- Network analysis: packets moving along a node graph
- Forensics: evidence folder and magnifying-glass sweep
- Frameworks: linked source cards and relationship graph
- Utilities: terminal cursor and rotating gear

No external image host or runtime dependency is required. The artwork is decorative and uses inline SVG styling/animation. Animations respect `prefers-reduced-motion` in supporting browsers.
