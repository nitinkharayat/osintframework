03 / ABOUT FIELDNOTES

A directory, not a shortcut.

Fieldnotes is a lightweight static reference to open-source OSINT and security tooling. The goal is to make dependable tools easier to discover without hiding the context behind a flashy interface.

Some projects offer commercial editions or optional hosted services; those differences are noted where relevant. Confirm the upstream license, release status, dependencies, and platform support before relying on a tool.
